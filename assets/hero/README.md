# トップのメイン写真をここに置いてください

トップページ最上部（ヒーロー）の大きな背景写真です。
下のファイル名で画像を入れると自動で表示されます。
**写真が無い間は、やわらかいピンクのグラデーションが表示されます**（何も壊れません）。

## ファイル名
`hero-cat.jpg`

## 写真の推奨
- **横長**の写真（画面いっぱいに背景として表示されます）
- 親猫と子猫、または子猫のアップなど、**あたたかく寄り添う雰囲気**が理想
- 横 1600px 以上、1枚 500KB 以下が目安
- 左側に文字が乗るので、**被写体は右寄り**の写真だとキレイに収まります
- 自分で撮影した写真、または利用許諾のある写真のみ

## 追加のしかた
1. `hero-cat.jpg` を用意して、このフォルダ（`assets/hero/`）に入れる
2. GitHub にコミット＆プッシュ → Railway が自動再デプロイ → 表示されます

※ 難しければ写真を送ってもらえればこちらで配置します。
