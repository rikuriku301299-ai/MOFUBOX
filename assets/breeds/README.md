# 猫種の写真をここに置いてください

トップページ「人気の猫種から探す」のカードに表示される写真です。
下のファイル名で画像をこのフォルダ（`assets/breeds/`）に入れると、自動で表示されます。
**画像が無い猫種は、これまで通り絵文字が表示されます**（何も壊れません）。

## ファイル名（この名前にしてください）

| 猫種 | ファイル名 |
|------|-----------|
| スコティッシュフォールド | `scottish-fold.jpg` |
| マンチカン | `munchkin.jpg` |
| アメリカンショートヘア | `american-shorthair.jpg` |
| ラグドール | `ragdoll.jpg` |
| ノルウェージャンフォレスト | `norwegian-forest.jpg` |
| メインクーン | `maine-coon.jpg` |
| ベンガル | `bengal.jpg` |
| ペルシャ | `persian.jpg` |

## 写真の推奨

- **形**：正方形に近い写真（丸くトリミングして表示されます）
- **サイズ**：おおよそ 400×400px 以上、1枚 300KB 以下が目安
- **形式**：`.jpg`（`.png` を使う場合は index.html の拡張子も合わせて変更が必要）
- **権利**：必ず自分で撮影した写真、または利用許諾のある写真を使ってください

## 追加のしかた

1. 上記のファイル名で画像を用意する
2. このフォルダ（`assets/breeds/`）に入れて GitHub にコミット＆プッシュ
3. Railway が自動で再デプロイ → 写真が表示されます

※ 操作が難しければ、写真を送ってもらえればこちらで配置します。
