# モフログ — 猫グッズ特化アフィリエイトサイト

MOFUBOX とは別の収入源として作った、**アフィリエイト収益用の静的サイト**です。
記事を push するだけで自動ビルド&自動デプロイされ、読者が記事内のリンクから商品を買うと紹介料が入ります。紹介料の発生に飼い主(あなた)の操作は不要——つまり**寝ている間に発生しうる収益**はこの部分です。

## 最初に正直な話(必読)

**「コードを動かすだけで勝手にお金が増える仕組み」は世の中に存在しません。** それを謳うものは全部詐欺です。このサイトが現実にできるのは次のことです。

- 収益の式は **アクセス数 × クリック率 × 購入率 × 紹介料率**。自動化できるのは「サイトの運用」であって「アクセスを集めること」ではありません。
- 立ち上げから数ヶ月は**収益ゼロが普通**です。検索エンジンに評価されるまで時間がかかります。
- 伸ばす鍵は (1) 記事数を増やす(Claudeに書かせて push するだけ)、(2) MOFUBOX のリールやSNSからこのサイトへ導線を張る、の2つです。
- 逆に、一度記事が検索やSNS経由で読まれ始めれば、その後は本当に放置で紹介料が発生します。「仕込みは能動的、回収は受動的」がアフィリエイトの正しい理解です。

## 収益が発生する仕組み

1. 読者が記事内の「Amazonで見る」「楽天で見る」ボタンを押す
2. リンクにあなたのアフィリエイトIDが付いているので、その後の購入があなたの成果として記録される
3. Amazon/楽天から紹介料(商品カテゴリにより購入額の約2〜8%)が支払われる

## あなたにしかできない初期設定チェックリスト

コードは完成していますが、以下は**アカウント登録が必要なため人間にしかできません**。上から順に、合計1〜2時間程度です。

- [ ] **1. GitHub Pages を有効化** — リポジトリの Settings → Pages → Source を「GitHub Actions」にする。これだけでサイトが `https://rikuriku301299-ai.github.io/MOFUBOX/` に公開されます(以後は push のたび自動更新)。
- [ ] **2. もしもアフィリエイトに登録**(<https://af.moshimo.com/>) — Amazon・楽天の両方をここ経由で扱えて、個人サイトでも審査が通りやすい定番。楽天の商品リンクを作ったら `products.json` の `rakutenUrl` に貼る。
- [ ] **3. Amazonアソシエイトに登録**(<https://affiliate.amazon.co.jp/>) — 承認されたら発行されるトラッキングID(例: `xxxx-22`)を `config.json` の `affiliates.amazonTag` に記入。※審査には「180日以内に3件の成果」が必要なので、先にサイトを公開しSNSで数記事流してから申請するのがコツ。
- [ ] **4. 商品を実物に差し替え** — `products.json` の各商品はいまカテゴリの代表例(ASIN空欄)です。Amazonで実際に紹介したい商品を選び、商品ページURLの `/dp/` の後ろにある10桁(ASIN)を `asin` に記入。空欄のままでも検索リンクで動作はしますが、成果率が大きく下がります。
- [ ] **5. 導線を張る** — MOFUBOXのフッターやリール、SNSプロフィールからモフログへリンク。`config.json` の `mofuboxUrl` にMOFUBOXのURLを入れると全ページのフッターに相互リンクが出ます。
- [ ] (任意) **6. Google AdSense** — 記事が10〜20本たまってから申請。承認されたら `affiliates.adsenseClientId` に `ca-pub-...` を記入するとクリック型広告も併用できます。
- [ ] (任意) **7. 独自ドメイン** — 本気で育てるなら年1,500円程度で取得し、Pages のカスタムドメインに設定。`config.json` の `siteUrl` も変更。

## 日々の運用(=寝ている間に回る部分)

- **記事の追加**: `mofulog/articles/` に `.md` を1枚置いて push するだけ。GitHub Actions が自動でビルドし、サイト・サイトマップ・RSSまで更新します。「〇〇について記事を書いて」とClaudeに頼めば、あなたの作業は push の確認のみです。
- **収益の確認**: Amazonアソシエイト/もしもの管理画面で見ます(このリポジトリには何も届きません)。
- **ビルド警告**: `node mofulog/build.js` を実行すると、未設定のアフィリエイトIDや空欄のASINを一覧で警告します。ゼロになれば収益化設定は完了です。

## 記事の書き方

```markdown
---
title: 記事タイトル
description: 検索結果に出る説明文(80〜120字)
date: 2026-07-10
slug: url-ni-naru-eigo
---

# 見出し(h2になる)

本文。**太字**と[リンク](https://example.com)が使えます。

- 箇条書き

> 補足の引用ボックス

{{product:feeder-basic}}   ← products.json の slug を指定すると商品カードが入る
```

## ローカルでの確認

```bash
node mofulog/build.js        # dist/ に生成 + 収益化の未設定項目を警告
npx serve mofulog/dist       # または好きな静的サーバーでプレビュー
```

## 法律まわり(対応済み)

- **ステマ規制(景品表示法)**: 2023年10月から、広告であることの明示が義務です。全ページ先頭に「当サイトはアフィリエイト広告を利用しています」を自動挿入しています。
- **Amazonアソシエイト規約**: アソシエイトである旨の表示が必須。上記の表記がこれを兼ねます。
- 商品リンクには `rel="sponsored"` を自動付与しています(Googleのガイドライン対応)。
